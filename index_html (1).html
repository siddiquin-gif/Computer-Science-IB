S1 Your First Print Statement ⬛ Easy

In Python, print() is used to display text on screen. The text must be wrapped in quotation marks inside the brackets.

# This is a comment — Python ignores it print("Hello, World!")

👆 The example above prints a greeting. Now try it yourself:

  • Type the code above into your Python editor (IDLE or Thonny).
  • Run it with F5 or the Run button.
  • Change the message to "Hello, [your name]!" and run again.
  • Add a second print() line that shows your school name.
Hello, Alex! Greenfield Academy
S2 Storing Values in Variables ⬛ Easy

A variable is a labelled container that stores data. Use = to assign a value. Variable names should be lowercase with underscores.

name = "Sofia" # string age = 14 # integer height = 1.62 # float print("Name:", name) print("Age:", age)
  • Create three variables: name, age, and favourite_colour.
  • Assign appropriate values to each.
  • Print a sentence using all three variables.
💡 You can combine variables and text in print by separating them with commas: print("I am", age, "years old")

C1 User Input — Personal Profile ⬛⬛ Medium

input() pauses the program and waits for the user to type something. It always returns a string. The message inside the brackets is shown as a prompt.

name = input("What is your name? ") age = input("How old are you? ") print("Hello", name, "- you are", age, "years old.")
  • Write a program that asks for: first name, last name, age, and favourite subject.
  • Store each answer in an appropriately named variable.
  • Print a full sentence using all four variables.
  • Use f-strings for your print statement: f"Hello {name}!"
What is your first name? Jordan What is your last name? Smith How old are you? 15 Favourite subject? Computer Science Hello Jordan Smith! You are 15 years old and love Computer Science.
💡 An f-string starts with f before the quote: f"Hello {name}, you are {age}!" — variable names go inside curly braces.
C2 Arithmetic & Type Casting ⬛⬛ Medium

Python can do maths! But input() gives you a string, not a number. You must cast (convert) it using int() or float() before calculating.

# Python arithmetic operators: # + addition - subtraction # * multiplication / division # // floor division % modulo ** power num1 = int(input("Enter first number: ")) num2 = int(input("Enter second number: ")) print("Sum:", num1 + num2) print("Product:", num1 * num2)
  • Ask the user for two whole numbers.
  • Display the result of all six operations: + - * / // %
  • Label each result clearly in the output.
  • Extend: Ask for a third number and calculate the average of all three.
Enter first number: 17 Enter second number: 5 Addition: 22 Subtraction: 12 Multiplication: 85 Division: 3.4 Floor Division: 3 Modulo: 2
C3 Data Types Detective ⬛⬛ Medium

Python has several data types. Use type() to find out what type a value is. Understanding types prevents common errors.

# The four main types you'll use today: a = 42 # int — whole number b = 3.14 # float — decimal number c = "Python" # str — text d = True # bool — True or False print(type(a)) # <class 'int'>
  • Create one variable of each type: int, float, str, bool.
  • Print each variable and its type using type().
  • Try adding a string to an integer — what error do you get? Write it down.
  • Fix the error using str() conversion.
⚠️ You cannot do "Age: " + 15 — you must write "Age: " + str(15). This is called concatenation.

CH1 BMI Calculator ⬛⬛⬛ Hard

Build a Body Mass Index calculator. BMI = weight (kg) ÷ height² (m). You will need to handle float inputs, perform arithmetic, and round the result.

  • Ask the user for their weight in kg (float) and height in metres (float).
  • Calculate BMI using the formula: bmi = weight / (height ** 2)
  • Round the result to 2 decimal places using round(bmi, 2).
  • Display the result in a formatted sentence.
  • Bonus: Display the BMI category (Underweight / Normal / Overweight / Obese) using if/elif/else.
Enter your weight (kg): 68.5 Enter your height (m): 1.75 Your BMI is 22.37 Category: Normal weight
💡 BMI ranges: <18.5 = Underweight · 18.5–24.9 = Normal · 25–29.9 = Overweight · 30+ = Obese
CH2 Receipt Generator ⬛⬛⬛ Hard

Create a simple shop receipt program. The user enters item names and prices, and your program produces a formatted receipt with a total.

  • Ask for the names and prices of 3 items.
  • Calculate the subtotal, apply 20% VAT, and calculate the total.
  • Print a formatted receipt — use string formatting to align the columns neatly.
  • Use f"{'Item':<20}{'Price':>8}" style formatting for alignment.
# Hint: f-string alignment print(f"{'Item':<20}{'Price':>8}") print("-" * 28) print(f"{'Notebook':<20}{'£2.99':>8}")
============================ RECEIPT ============================ Notebook £2.99 Pencil case £4.50 USB stick £12.99 ---------------------------- Subtotal £20.48 VAT (20%) £4.10 ---------------------------- TOTAL £24.58 ============================
